# Trading Journal

## Author
Hansome Anthony

## About the Project

Trading Journal is a Python application I developed to help cryptocurrency traders record and track their trades and calculate their profit or loss over time.

I built this project as part of my software development learning journey to practice Python programming, file handling, data validation, and problem-solving.

## Features

- Record cryptocurrency trades.
- Track assets, trade directions, entry prices, and exit prices.
- Record leverage and margin amounts.
- Calculate profit and loss.
- Review trading performance over time.
- Store trade records in a CSV file.

## Technologies Used

- Python
- CSV file handling
- Date and time handling

## How to Run

1. Install Python on your computer.
2. Clone this repository.
3. Open the project folder in your terminal.
4. Run the following command:

   python trading_journal.py
